# Infi-Pixi

Пиксельарт-редактор на бесконечном холсте. Рассчитан в первую очередь на телефон/планшет со стилусом, работает и на ПК.

**Живая версия:** https://yuriyvotintsev.github.io/Infi-Pixi/ (деплоится автоматически на каждый push).
Добавьте `?debug`, чтобы открыть консоль (eruda) прямо на телефоне.

## Управление

| | Телефон / планшет | ПК / Mac |
|---|---|---|
| Рисовать | стилус | левая кнопка мыши |
| Ластик | обратный конец стилуса или кнопка в панели | `E` |
| Пипетка | кнопка на стилусе или в панели | `I` |
| Двигать | один или два пальца | пробел + перетаскивание, средняя/правая кнопка, скролл тачпада |
| Зум | щипок | колесо, щипок на тачпаде, `+` / `-` |
| Отмена / повтор | тап двумя / тремя пальцами | `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z` |
| Размер кисти | кнопка в панели | `[` / `]` |

Если стилуса нет, в меню можно включить «Рисовать пальцем»: тогда один палец рисует, а два двигают холст.

## Стек

Vite + TypeScript, PixiJS v8 (WebGL), Svelte 5 (UI), IndexedDB (`idb-keyval`).

```
src/engine/   движок без зависимости от UI: чанки, камера, история, ввод, рендер, хранение
src/ui/       Svelte-компоненты поверх холста
```

Холст разбит на чанки 64×64, они создаются по мере рисования, рендерятся только видимые.

## Разработка

```sh
npm install
npm run dev      # http://localhost:5173, доступно и по локальной сети
npm run check    # проверка типов
npm run build
```
